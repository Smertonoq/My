# Математика для искусственного интеллекта

Учебный модуль для школьников: функции, производные, векторы и матрицы с постоянной связью с задачами машинного обучения и нейронных сетей.

Материалы написаны как **самостоятельные учебные главы**, а не как конспекты преподавателя. Их можно читать без устного сопровождения: определения вводятся перед использованием, формулы поясняются словами, вычисления разобраны по шагам, а в конце каждой темы есть вопросы для самопроверки.

## Для кого

Основной уровень — 8–11 классы. Материал не предполагает предварительного знания математического анализа или линейной алгебры.

Для 8–9 классов строгую запись предела и отдельные формальные замечания можно воспринимать как дополнительный материал. Для 10–11 классов главы можно проходить полностью.

## Как устроены материалы

Каждая лекция построена как глава учебника:

- новая идея сначала объясняется словами;
- затем вводится математическая запись;
- после формулы разбирается числовой пример;
- регулярно показывается связь с искусственным интеллектом;
- в конце есть самопроверка и ссылки для углубления.

Практикумы можно читать прямо на GitHub. Решения задач спрятаны в раскрывающихся блоках `<details>`, поэтому ученик сначала может решить задачу самостоятельно, а затем открыть разбор.

## Формулы на GitHub

GitHub поддерживает математические формулы в Markdown. В материалах используются:

```markdown
$y=f(x)$
```

для формул внутри строки и

```markdown
$$
y=wx+b
$$
```

для отдельных формул.

## Логика модуля

Материал идёт от простого математического объекта к механизму обучения модели:

```text
функция
→ производная
→ функция ошибки
→ градиентный спуск
→ вектор
→ матрица
→ слой нейросети
→ градиент как вектор
```
